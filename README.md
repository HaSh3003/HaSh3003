## 👨‍💻 About Me

I build software end to end — the web app, the desktop client, the mobile app, the API, the database and the server it all runs on. Eight years in, across ERP systems, e‑commerce platforms, dashboards and consumer apps, most of it running in production today.

- 🔭 **Currently at [Akira](https://akiradvertising.com)** — building and running web platforms, business systems and mobile apps for clients across the region.
- 🧠 **Currently learning: operating system development.** Writing a kernel from scratch — bootloader, memory management, interrupts and a scheduler — in **C** and **x86 assembly**, debugged on **QEMU/GDB**. The best way I know to understand what runs under every framework I use.
- ⚙️ **Full‑stack in the literal sense** — Laravel/PHP and .NET on the back, React/Next.js on the front, React Native on mobile, .NET on the desktop, and Linux under all of it.
- 🏗️ **Comfortable owning the whole thing:** architecture, database design, APIs, CI/CD, deployment, monitoring and the 2 a.m. production fix.
- 👯 **Open to collaborating on** modern web platforms, Laravel/Filament products, mobile apps and anything low‑level and systems‑flavoured.
- 💬 **Ask me about** Laravel & Livewire, .NET & C#, React & React Native, database design, or how a bootloader hands control to a kernel.
- 📝 I write at **[roayatk.netlify.app/blog](https://roayatk.netlify.app/blog)** · portfolio at **[hash-dev.info](https://hash-dev.info)**
- 📫 **perfecto.dev@programmer.net**
